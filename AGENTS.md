# MarketSarthi agent instructions

Before changing this repository, read `PROJECT_CONTEXT.md` as the current product and technical source of truth.

After every material product, workflow, API, schema, UI, setup, or architecture change:

1. Update the relevant section of `PROJECT_CONTEXT.md`.
2. Add a dated entry to its change log.
3. Never add secret values to documentation; list environment-variable names only.
4. Keep claims evidence-safe: search visibility is a signal, not proof of demand or future sales.
